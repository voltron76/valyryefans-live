## 2026-06-19 - Added global focus-visible styles
**Learning:** The application lacked clear visual focus indicators for keyboard navigation across its interactive elements. Adding a global focus-visible rule is a highly effective, low-impact way to improve accessibility without disrupting mouse users.
**Action:** Always verify if a site has global focus states defined. If not, adding a single, well-targeted `focus-visible` rule in the main stylesheet is a scalable a11y quick-win.
