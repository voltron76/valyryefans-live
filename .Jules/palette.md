## 2026-07-01 - Accessible Post Action Buttons
**Learning:** When using mixed-content buttons (icons + text) where the text updates dynamically (like a like count), putting the comprehensive description in an 'aria-label' on the button and hiding the internal text with 'aria-hidden="true"' provides a cleaner, singular announcement for screen readers rather than fragmented or double-read text.
**Action:** Apply this pattern consistently across all dynamic, icon-heavy action buttons in the UI.
